# Проект "Меню с чекбоксами"

Небольшое веб-приложение из двух страниц.

## Функциональность
- Первая страница — приветствие и ссылка на меню
- Вторая страница — переключение между типами меню (радио-кнопки)
- Динамическое отображение пунктов из JSON
- Подсчет выбранных пунктов и их суммы в заголовке

## Технологии
- HTML
- CSS
- JavaScript (чистый, без фреймворков)

## Как запустить
Просто откройте `index.html` в браузере.
